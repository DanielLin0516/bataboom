隐私政策

最后更新：2026 年 10 月 2 日

Bataboom!（以下简称“本 App”）不收集任何个人数据，不会把个人数据存储在我们的服务器上，也不会分享给任何人。我们没有服务器、没有账号系统、没有统计分析，也没有广告。

留在你设备上的数据

  • 游戏数据（成绩、设置、已解锁的装备）存储在你的 Apple Watch 上，并通过 Apple 的 WatchConnectivity 同步一份到你自己配对的 iPhone 上的 Bataboom! App。这些数据永远不会传给我们。
  • 运动传感器只在游戏画面打开时读取，用来检测挥棒。运动数据在手表上处理，不会保存，也不会发送到任何地方。

由你控制的 Apple 服务

  • iCloud：你的进度（成绩和已解锁的装备）通过 Apple 的 iCloud 键值存储备份在你自己的 iCloud 账号中，重新安装 App 或换新手表时都能找回。我们无法访问这些数据。
  • Apple 健康：如果你允许，本 App 会把你的游戏过程作为棒球体能训练（含活动能量）保存到 Apple 健康中。本 App 不读取任何健康数据。你可以在本 App 的设置或“健康”App 中关闭此功能。
  • Game Center：如果你已登录，你的成绩和成就会依照 Apple 的隐私政策发送到 Apple 的 Game Center。不使用 Game Center 也能完整使用本 App。

本网站

  • 没有 Cookie、没有统计分析、没有广告，也没有第三方请求：字体、图片和视频都由本站自己提供。
  • 如果你在菜单中选择了语言，这个选择会保存在你设备上浏览器的本地存储中，下次打开网站时就会显示该语言。它永远不会发送给我们。
  • 本站托管在 GitHub Pages 上。出于安全考虑，GitHub 可能会依照 GitHub 隐私声明记录你的 IP 地址等技术数据。

儿童

本 App 不收集任何人的个人数据，包括儿童。

政策变更

如果本政策有变更，我们会更新本页面及顶部的日期。
