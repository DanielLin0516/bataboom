利用規約

最終更新日：2026年10月2日

Bataboom! は、Apple のライセンス Application エンドユーザ使用許諾契約（App Store の標準 EULA）に基づいて使用が許諾されます。本規約は、Bataboom! に固有のいくつかの事項を補足するものです。両者が矛盾する場合は、Apple の EULA が優先されます。

安全に遊ぶために

  • Bataboom! は腕を振って遊ぶゲームです。振る前に周りを確認し、人やペット、壊れやすい物から離れて、バンドをしっかり締めてください。
  • どこで、どのように遊ぶかはご自身の責任となります。歩きながら、運転中、そのほかスイングで人にけがをさせるおそれのある場所では遊ばないでください。
  • 腕、手首、肩が痛むときは休憩してください。

計測器ではなく、ゲームです

  • 飛距離、打球速度、スイング速度は、Apple Watch の動きから算出したお遊びの推定値であり、実測ではありません。
  • ヘルスケアに保存されるワークアウトは Apple の推定値を使っており、参考情報にすぎません。Bataboom! は健康やトレーニングに関する助言を行いません。

購入について

  • Bataboom! は App Store での買い切りアプリです。広告もアプリ内課金もなく、ロッカールームのアイテムはすべてプレイで手に入れます。
  • 支払いと返金は Apple が取り扱います。返金のご依頼：reportaproblem.apple.com

Game Center とデータについて

ランキングと実績は、Apple の規約に基づき Apple の Game Center が提供します。Bataboom! はデータを収集しません。詳しくは プライバシーポリシー をご覧ください。
