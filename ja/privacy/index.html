プライバシーポリシー

最終更新日：2026年10月2日

Bataboom!（以下「本アプリ」）は、個人データを収集することも、当方のサーバーに保存することも、第三者と共有することもありません。当方はサーバー、アカウント、解析ツール、広告のいずれも使用していません。

お使いのデバイスに保存されるもの

  • プレイデータ（成績、設定、アンロックしたアイテム）は Apple Watch に保存されます。Apple の WatchConnectivity を通じて、ペアリング済みのご自身の iPhone 上の Bataboom! アプリにコピーが送られます。当方に届くことはありません。
  • モーションセンサーは、スイングを検出するため、ゲーム画面を開いている間だけ読み取ります。モーションデータは Apple Watch 上で処理され、保存も送信もされません。

ご自身で管理できる Apple のサービス

  • iCloud：進行状況（成績とアンロックしたアイテム）は、Apple の iCloud キー値ストレージを使ってご自身の iCloud アカウントにバックアップされ、本アプリの再インストールや新しい Apple Watch でも元に戻ります。当方がアクセスすることはできません。
  • ヘルスケア：許可した場合、本アプリはプレイしたセッションを野球のワークアウト（アクティブエネルギーを含む）としてヘルスケアに保存します。健康データは読み取りません。本アプリの設定、またはヘルスケア App でオフにできます。
  • Game Center：サインインしている場合、成績と実績は Apple のプライバシーポリシーに基づき Apple の Game Center に送信されます。Game Center なしでも本アプリはすべての機能を利用できます。

このウェブサイトについて

  • Cookie、解析ツール、広告、第三者へのリクエストは一切使用していません。フォント、画像、動画はすべてこのサイトから配信しています。
  • メニューから言語を選ぶと、その選択はお使いのデバイスのブラウザのローカルストレージに保存され、次回からその言語でサイトが開きます。当方に送信されることはありません。
  • 本サイトは GitHub Pages でホストされています。GitHub はセキュリティのために IP アドレスなどの技術データを記録する場合があります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

お子さまについて

本アプリは、お子さまを含め、どなたからも個人データを収集しません。

本ポリシーの変更

本ポリシーを変更する場合は、このページと冒頭の日付を更新します。
