개인정보 처리방침

최종 업데이트: 2026년 10월 2일

Bataboom!(이하 “앱”)은 어떠한 개인정보도 수집하거나, 저희 서버에 저장하거나, 공유하지 않습니다. 저희는 서버, 계정, 분석 도구, 광고를 운영하지 않습니다.

기기에만 저장되는 정보

  • 게임 데이터(점수, 설정, 잠금 해제한 아이템)는 Apple Watch에 저장됩니다. 사본은 Apple의 WatchConnectivity를 통해 본인과 페어링된 iPhone의 Bataboom! 앱으로 전송되며, 저희에게는 전달되지 않습니다.
  • 모션 센서는 스윙을 감지하기 위해 게임 화면이 열려 있을 때만 사용됩니다. 모션 데이터는 워치에서 처리되며 저장되거나 어디로도 전송되지 않습니다.

직접 관리하는 Apple 서비스

  • iCloud: 진행 상황(점수와 잠금 해제한 아이템)은 Apple의 iCloud 키-값 저장소를 통해 본인의 iCloud 계정에 백업되어, 앱을 다시 설치하거나 새 워치를 사용할 때 복원됩니다. 저희는 이 데이터에 접근할 수 없습니다.
  • 건강 앱: 허용한 경우, 앱은 플레이 세션을 야구 운동(활동 에너지 포함)으로 건강 앱에 저장합니다. 건강 데이터는 읽지 않습니다. 앱의 설정이나 건강 앱에서 끌 수 있습니다.
  • Game Center: 로그인한 경우, 점수와 업적이 Apple의 개인정보 처리방침에 따라 Apple의 Game Center로 전송됩니다. Game Center 없이도 앱의 모든 기능을 사용할 수 있습니다.

이 웹사이트

  • 쿠키, 분석 도구, 광고, 제3자 요청이 없습니다. 글꼴, 이미지, 동영상은 모두 이 사이트에서 제공됩니다.
  • 메뉴에서 언어를 선택하면, 다음 방문 시 그 언어로 열리도록 선택 내용이 기기의 브라우저 로컬 저장소에 저장됩니다. 저희에게 전송되지 않습니다.
  • 이 사이트는 GitHub Pages에서 호스팅됩니다. GitHub는 보안을 위해 IP 주소 등의 기술 데이터를 기록할 수 있으며, 이는 GitHub 개인정보 처리방침을 따릅니다.

아동

앱은 아동을 포함한 누구의 개인정보도 수집하지 않습니다.
