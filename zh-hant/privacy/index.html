隱私權政策

最後更新：2026 年 10 月 2 日

Bataboom!（以下稱「本 App」）不收集、不在我們的伺服器上儲存，也不分享任何個人資料。我們沒有伺服器、沒有帳號系統、沒有分析工具，也沒有廣告。

留在你裝置上的資料

  • 遊戲資料（成績、設定、已解鎖的裝備）儲存在你的 Apple Watch 上，並透過 Apple 的 WatchConnectivity 傳一份副本到你自己配對的 iPhone 上的 Bataboom! App。這些資料永遠不會傳給我們。
  • 動作感測器只在遊戲畫面開啟時讀取，用來偵測揮棒。動作資料在手錶上處理，不會儲存，也不會傳送到任何地方。

由你掌控的 Apple 服務

  • iCloud：你的進度（成績和已解鎖的裝備）會透過 Apple 的 iCloud 鍵值儲存，備份在你自己的 iCloud 帳號中，重新安裝 App 或換新手錶時都能找回。我們無法存取這些資料。
  • 「健康」App：如果你允許，本 App 會把遊戲時段存成棒球體能訓練（含活動能量）記錄在「健康」App 中。本 App 不讀取任何健康資料。你可以在本 App 的設定或「健康」App 中關閉這項功能。
  • Game Center：如果你已登入，你的成績和成就會依照 Apple 的隱私權政策傳送到 Apple 的 Game Center。不使用 Game Center 也能完整使用本 App。

本網站

  • 沒有 Cookie、沒有分析工具、沒有廣告，也不會向第三方發出請求：字型、圖片和影片都由本網站提供。
  • 如果你從選單選擇語言，你的選擇會儲存在你裝置上瀏覽器的本機儲存空間，下次打開網站時就會顯示該語言。這項設定不會傳送給我們。
  • 本網站架設在 GitHub Pages。GitHub 可能會基於安全目的記錄 IP 位址等技術資料，詳見 GitHub 隱私權聲明。

兒童

本 App 不向任何人收集個人資料，包括兒童。

政策變更

如果本政策有所變更，我們會更新此頁面及頁首的日期。
